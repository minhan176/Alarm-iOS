# Alarm Sound Setup

## Bạn cần thêm file âm thanh báo thức

1. Tải một file âm thanh MP3 (ví dụ: từ [freesound.org](https://freesound.org/) hoặc bất kỳ nguồn nào)
2. Đổi tên file thành `alarm_sound.mp3`
3. Đặt file vào thư mục `assets/sounds/`

## Hoặc sử dụng âm thanh mặc định của hệ thống

Nếu không có file `alarm_sound.mp3`, app sẽ sử dụng âm thanh thông báo mặc định của hệ thống.

## Gợi ý nguồn âm thanh miễn phí:
- https://freesound.org/search/?q=alarm
- https://mixkit.co/free-sound-effects/alarm/
- https://www.zapsplat.com/sound-effect-category/alarms/

## Lưu ý:
File âm thanh phải có định dạng MP3 hoặc WAV và tên phải là `alarm_sound.mp3`
